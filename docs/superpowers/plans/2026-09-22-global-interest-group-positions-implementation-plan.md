## 5. 集中验证

新增一个小型检查入口：`tests/check_global_ig_positions.py`。复用仓库现有 Paradox 解析函数，不引入框架或通用解释器项目。检查应读取实际理念与 effect 脚本，不只测试复制出的模型。

至少覆盖：

- 八项对象与允许差异，尤其用户修订后的实业家五项固定值；
- 指定集团门控，源缺失、目标已存在、源目标共存、重复补挂；
- 小市民治安变体不作用于军队，其他定向变体不全局修改原型；

- 上游后期转换能够识别发展主义，现代个人主义及无关分支不变；
- 原版依赖源技术 ID 的必要引用接续及源定义漂移检测。

实现后运行新检查、本地化检查、`tests/check_eastern_accessibility.py` 和 `git diff --check`。具体依赖参数由脚本声明读取；不得把未运行检查记为通过。已有 Rhomaic PowerShell 检查在本机缺少 `pwsh`，不自动安装；涉及其保护对象时将必要断言纳入本次 Python 检查，并明确未运行原 PowerShell 脚本。
