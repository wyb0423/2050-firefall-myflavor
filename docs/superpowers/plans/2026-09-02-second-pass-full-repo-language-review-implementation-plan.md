1. 提取八份本地化文件的键、值、文件和行号。
2. 比较三组主本地化与 replace 本地化的英文／简中键集合。

5. 对候选键读取对应脚本定义、调用方与上游覆盖来源。

## 3. Task 2：共享身份与短文本

文件：

- `localization/*/ffpa_l_*.yml`
- `localization/replace/*/zzzz_ffpa_country_variable_tooltip_l_*.yml`

处理国家名、形容词、文化、政体、党名、利益集团、意识形态、国家集团名称、共同体 UI、modifier 和通用 fallback。短文本只做必要窄改，避免为了变化而变化；保留动态表达式和最新进度条提示。

## 4. Task 3：GRE/BYZ 内容链

核对并审校：

- 希腊民族主义日志与 `greece.1/.4/.5`；
- `formation.3` 与 GRE → BYZ 成立；
- BYZ 共同体、首都、新罗马、七条复归战役；
- 西方整合事件与永久选择；

历史材料保持“档案与当代再解释”定位，失败路线准确叙述人口迁移、故土移除和实际惩罚。

## 5. Task 4：TUR 内容链

文件：

- `localization/*/ffpa_turkish_flavor_l_*.yml`
- `localization/*/ffpa_l_*.yml` 中 TUR 既有键

## 6. Task 5：常驻治理与地区建设

文件：

- `localization/*/ffpa_permanent_governance_l_*.yml`
- `localization/*/ffpa_l_*.yml` 中十五项地区建设和西方整合键

四项常驻日志使用长期制度语言，准确说明计时、警告、破裂、修复、衰减与永久结果。十五项地区建设描述主权取得后的行政、交通、能源、市场和产业整合，不固定前所有者或开局政治形态。

## 7. Task 6：全局横扫

- “作为拜占庭／土耳其”等身份赘语；

不执行无上下文的全仓机械替换。
