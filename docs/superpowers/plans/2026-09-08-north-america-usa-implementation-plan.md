## 3. 静态可行性与后续实机验收：分裂州与工程遗产

测试包 README 给出四个显式控制台 effect，当前机器不执行。以后在可运行的机器上按 setup、partial、merge 顺序，在每次立即、推进一天、存读档后记录 report。错误国家与重复调用应拒绝执行。当前开发使用已查到的原版接口、保守对象生命周期处理和静态回归，不把未知运行结果当作已通过。

| 观察结果 | 实施决定 |
|---|---|
| 原 state 保留，标记保留 | 仍须测分割与最终合并；不能只凭第一次转移决定使用 state 引用 |
| 原 state 消失 | 领土成功判断不能只保存 state 引用，改用有静态省份先例支持的稳定目标来源；必须证明完整原目标转入 |
| modifier 丢失 | 增加有限工程来源记录和一次恢复，而非向整州或全国重新发放 |
| modifier 复制/叠加 | 记录工程唯一身份，按实际工程来源去重；不得靠“has_modifier”存在检查宣称无叠层 |
| 回调时序导致暂时查不到对象 | 生命周期入口只做标记，必要时下一月按稳定来源核实；不在空 scope 上推断完成 |

动态快照若需要大规模逐省展开或缺少可靠接口，先明确成本与替代行为，修订设计后才能进入正式领土逻辑；不能悄悄改成“得到同州任意一小块就完成”。

临时宣称单独检查：启动前已有来源必须保留；对启动后其他系统重复授予、无法区分来源的情形采取保守保留，不宣称引擎具有实际不存在的来源追踪能力。

## 5. 前身阶段

1. 严格前身身份与 49 州地理查询；排除革命临时实体；只处理实际持有本土的白名单国家。
2. 本地建设选择、目标固定、12 个月连续达标、工程唯一奖励与遗产处理。按可达资源和科技提供方向，测试无港口、无铁路、分裂州。
3. 领土目标候选：同州邻接优先，其次相邻州；排除分权、自己、附属国与范围外目标。UI 展示实际目标及失败/清理规则。
4. 保存经验证的目标来源、10 年期限、临时宣称来源、成功与失败冷却。成立 USA 时清理前身临时状态但不删除实际建筑/工程。
5. 自有外交战略仅偏向活动目标，不复制或注入外部 Core Balance 所拥有的战略。不增加全世界征服偏好，不自动 annex。
6. 比较规定依赖与可选 Core Balance 下的战略权重和实际选择；相同开局观测日志目标、AI 战略、外交博弈与方向。静态权重差异不能代替跑局。
7. 同步实现 `ffpa_na_flavor.1–5`：工程提案、实际进展、统一倡议、目标接收与未完成结算，参照设计第 6.9 节，不为各前身复制同义事件。
8. `.4` 成功结算落实已确认的五年奖励：全国威望 +10%、合法性 +5；选择目标地区建设效率 +25% / 基础设施吞吐量 +20% / 制造业吞吐量 +10%，或税收能力 +25% / 整合速度 +50% / 动乱影响 -25%。两种方案均无额外支出；全国仅刷新期限，同州方案互斥刷新/替换，结算幂等，少量割地不能提前领取。

## 6. 美国阶段性内容

1. 国家成立与旧档 ensure：严格 USA，分别挂载政治、市场、教育入口；晚成立国家识别已有技术与产业，不发虚构首创奖励。
2. 四项政治选择：工程权限、产权、代表资格、拨款监督。通过持久选择值影响后续按钮，文本尊重实际政体。
3. 一次月度本土自有州/建筑扫描缓存人口加权接入、制造业总等级、occupancy < 65% 的工业等级、各州合格工业等级、教育节点和产业分布；JE、事件、常驻与 UI 共用，不遍历 pops、不自行汇总全国就业人数、不为各指标重复扫描。
4. 市场 → 工业、教育 → 科研分别推进。每个结算事件只发一次，等待玩家选项时不重新触发。
5. 研究中心仅消费上游建成状态；不提供绕过选址的新入口。核对十九世纪美国 JE/事件是否实际可达，有冲突才列出最小覆盖。
6. 两项重点教育/科研选择的持续代价已确认各为大学投入品消耗 +10%（合计 +20%），仅作用于大学建筑，取代大学工资方案。科研三个阶段稳定验收均为六个月；第三阶段具体清单按设计第 6.5.3 节。最终事件 ffpa_usa_flavor.24《档案之外》的完成选项通过唯一结算 effect 发放永久全国“自主创新体系”：生产科技研究速度 +5%、制造业吞吐量 +5%，与领先荣誉独立，不附加维护义务。新增独立完成奖励门控及双语修正名称和说明，重复事件、JE 完成回调、读档与 ensure 不得重复发放；旧档 ensure 不重置进度或期限。核对前期科研选择叠加后的最高永久生产研究速度 +20%。
7. 同步实现 `ffpa_usa_flavor.1–5`、`.10–14`、`.20–24`：国家身份、四项政治抉择、建设过程争议、经济与科研结算。事件既包括毕业反馈，也包括合同、工资、教育与知识公开的实际取舍。

### 6.0 已确认扩展：工业规模简化

按设计第 6.3、6.3.1、6.6.2、7.3 节执行。启动保存 L0 与固定目标 T = max(30, L0 + max(10, ceil(L0 × 25%)))，只计算已建成白名单等级；兼并所得可计入，不随 GDP、领土或读档重算目标。《夜班的工资单》首次达到 L0 + ceil((T - L0) / 2) 且存在 occupancy >= 0.75 的制造建筑时触发一次。集中奖励州按合格工业等级排序，不按就业人数排名。

常驻低就业等级占比：occupancy < 0.65 的制造等级 / 总制造等级，至少35%产生原定每月风险+1，不超过20%满足自然恢复的工业条件；总等级零视为100%。四类行业、三/五州、单建筑就业率与十八个月工业稳定期保持不变。

验证启动等级10/40/200对应目标30/50/250，非整倍数向上取整、零总等级、恰好65%就业率及35%/20%占比边界、在建等级不计入、兼并计入、目标与事件结算不重复；用共享缓存避免重复扫描，不将静态结构简化报告为实测性能提升。

## 7. 一项政治经济常驻

### 7.1 联邦的承诺

- 只有一个 JE。政治/经济任一前置完成即可挂载，另一领域后解锁原地加入；领域各自初始化一次，分别获得整备期。
- 信用与风险两条条目独立取值、危机时钟、收益档位与恢复条件；总体状态展示最严重项，不丢失另一项明细。
- 六个操作分别实现实际扣费、冷却、完成效果。紧急授权/信贷共用发展加速槽位，两项审查共用审查槽位；跨领域结算只触发一次。
- 政治失败 8 年、经济失败 5 年，各自取消本领域正常收益；不产生第三份联合惩罚，不关闭仍正常领域。
- 剔除本项修正对输入读数的直接贡献；实际经济恶化仍可造成政治后果。恢复期保留修复入口，不能无限续罚。
- 同步实现 `.30–31` 的听证与应急权后果，以及 `.40–41`、`.43–44` 的政治/经济危机与恢复。单领域失败通知不能取消另一领域正常状态。

### 7.2 事件层的独立施工与验收

参照 BYZ/TUR 的触发、镜头与选项结构，不复制其国家设定。设计第 6.9 节现列出 30 个节点，包含已确认的 `.6–9` 四个法律节点。无需每局全部出现，不新增 JE 数量；法律节点与政治线同步实现。

1. 为所有节点制作“调用入口 → readiness → pending → event → option effect → settled/cleanup”的登记，先确保状态机完整，再起草文本。
2. 新增两个独立 namespace：前身 `ffpa_na_flavor`、美国 `ffpa_usa_flavor`。检索事件 ID 冲突后固定编号，不改 `ffpa_flavor` 或 `ffpa_tur_flavor`。
3. 复用原版已存在的 event image、icon、sound，按叙事场景选择；新增 `.t/.d/.f`、选项及 tooltip 的双语键，保持 BOM。无需为此生成新美术资源。
4. 每场争议有实际可读代价：费用、有限修正、集团反馈或治理变量。实际工程奖励由唯一 effect 发放，事件与 JE 不双发。永久制度选择保留旧档语义。
5. 普通一次性争议共用 18 个月调度冷却；完成、失败、恢复不受其阻塞。等待选择时不得再次排程，失效时清 pending，默认选项可安全结算。
6. 严厉惩罚由失败状态机立即执行，弹窗不负责延迟施罚；重复 event、读档或未选择不能重复加罚、刷新期限或免罚。真实第二轮危机使用新一轮门控，不能被永久 fired 标记吞掉。
7. 剧情以实际国家、州、产业、法律与集团为依据；动态对象不存在时使用无专名降级文本。继承者、战争对手与州前所有者不得混用，旧档不捏造历史。
8. 文本审校与脚本验收同时完成：具体场景、利益主体和制度后果互相对应。不得只做一组完成/失败通知就报告风味事件全部实现。

### 7.3 已确认财政支出的实现

按设计第 7.1 节七类拨款实现，年支出比例为启动时全国年 GDP 的 0.25%、0.5% 或 0.75%，期限为已确认的一至三年。实现前核对 GDP 单位、周支出接口与相同作用域的原生先例；不能把年支出当成每周扣款。

启动时保存每周金额和到期状态，期间不动态追涨，不新增固定金额上下限；事件和按钮显示具体周费用与期限，日志显示叠加总额。允许赤字启动，不因普通财政波动自动取消。检查到期、对应项目取消和国家失效的费用清理，其他领域项目保持独立，重复执行与读档不重复扣款或重置期限。免费选项、审查、紧急授权及大学投入品消耗加成不得额外套用 GDP 拨款。

## 12. 近邻议程：省份范围核对与已确认奖励边界

本次核对当前原版地图文件、Tech & Res 与 Firefall 0.1.1；地图文件按相对路径覆盖处理，49 个本土州区域共 2,192 个省份，单个州区域为 2–159 个。与 Firefall 开局 create_state 的省份清单逐项比对，无遗漏或重复。此检查已加入 `check_north_america_preflight.py`，不证明其他数据库的最终合并或引擎运行行为。

### 目标快照与成本

- 原生 `common/script_values/occupation_values.txt` 在 state 数值上下文使用 `every_province`，但当前检索未找到同类别 effect 中枚举省份并保存持久列表的先例。不能直接把数值迭代器当作 effect 语法已验证。
- 已有 `transfer_province` 的 `p:ID.state` 提供稳定省份查询先例。保底方案可从 49 州地图源生成按州分组的省份调用，启动时只记录目标 state 当时持有的省份；后续只检查该州分组内的快照成员。单个活动议程最多检查 159 个候选省份，不做每国每月全美 2,192 省遍历。
- 正式实现前先确定省份持久集合接口；若采用生成清单，生成器及源覆盖检查一并交付，不能手抄 2,192 项。现已由 `tools/generate_north_american_provinces.py` 生成两个按州分组的访问/AI 查询表，配合国家上的省份布尔快照；生成表不保存当前开局所有者。
- 原生 `on_claim_added` 提供 claimant/region，但没有宣称来源参数；重复授予已有宣称是否再次回调仍未知。启动前的已有宣称必须保留，不能仅凭自有起始标记就声称识别了后来的所有外部来源。

### 已确认：合并后的接收州获得完整奖励

用户已选择完整奖励，取消按目标省份比例折算。实际接收目标领土的本国 state 获得所选方案的全部加成，允许原有领土共同受益；不授予同州区域内未接收目标领土的其他 state。

- 共同市场：建设效率 +25%、基础设施吞吐量 +20%、制造业吞吐量 +10%，五年。
- 共同政府：税收能力 +25%、地区整合速度 +50%、动乱影响 -25%，五年。
- 固定全国红利保持威望 +10%、合法性 +5%，五年；重复成功只刷新期限，不叠数值。
- 同州两种接收方案仍互斥，只有新的完整议程成功结算才能刷新或替换方案。普通兼并、割让、改标签和读档不得主动重发或刷新期限。

例如罗克福德开局 5 省全部并入芝加哥原有 5 省，必须 5/5 全部取得才完成；接收州获得完整共同市场或共同政府奖励。无需维护奖励比例及其动态重算。该规则已写入领土运行时；省份转移、州修正继承与游戏内效果尚未验证。

## 13. 近邻议程首版实现（2026-09-09）

- 一个可重复 JE 界面承载每轮十年目标、待接收与一年/三年冷却。目标启动后保存省份快照；原 state 引用消失不能证明成功，确认接收时再次核对全部省份所有权。
- .3 为启动/暂缓，.4 为共同市场/共同政府两选一，.5 解释已完成的失败/撤回清理，不追加惩罚。三场沿用现有 CMF 信件窗口；serial 和待接收状态阻止旧弹窗重复结算。
- 月度只检查一个目标州区域；选州使用原生 ordered_state，AI 空闲至多每年重选一次。选择按同州优先、其次人口排序；AI 排除违约、破产修正、无储备、恶名过高、战争/博弈及目标加直属宗主陆军投射超过本国的情形。这是保守筛选，不包含所有条约盟友、集团或未来参战者。
- 自有外交战略权重 1000；普通 Firefall 争夺故土初始约 80，可选 Core Balance 的相邻故土加宣称常见基数约 550，其他政治修正仍可能继续提高。额外州价值 +100，归还/征服评分 +300；只对仍持有登记省份的目标 state 生效，原所有者变化不扩大至第三国其他领土。不强制切换或宣战，实际选择未跑局。
- 和平门控保守使用本国任何战争/已参与外交博弈；到期或撤回时等待，不只筛选某一场相关冲突。源于既有 TUR 模式，避免活动外交期间移除权利；这可能延迟一次与目标无关的战争期间的结算。

- 成立 USA 或改 tag 通过成立回调取消未结算议程，冷却和已获修正保留。无本土/失去身份使用 JE invalid 清理；完全消亡后的引擎回调行为、读档及重新释放仍待实机核对。
