# USA 政府与利益集团身份

用户已确认实施：七类政府名称、八个集团名称、四个重点集团的五项理念。仅属于北美模块；不改国家名、旗帜、成立条件、法律效果、领袖、trait、既有会议及奖励。

## 显示名称

总统共和有选举为「联邦政府」，议会共和有选举为「联邦内阁」；无选举时分别为「总统执政府」「国会执政团」。君主制按独裁、非独裁无选举、有选举分别为「帝国政府」「帝国内阁」「立宪内阁」。统治者分别为总统、总理、主席、皇帝或女皇，继承者使用原生王子／公主称谓。

政府只匹配 strict USA，保留原生继承／换届回调。普通共和分支排除技术官僚制和一党制；摄政及王室领地联盟保留上游政府。其他治理原则回退上游。名称是政府称呼，不是动态国名；除「联邦政府」外均为架空制度的拟称。

八个利益集团依次为：军队「联邦军」、实业家「工商财团」、知识分子「学院派」、小市民「城镇公会」、地主「地产家族」、乡村民众「农场主」、虔信者「教会」、工会「劳工大会」。中英文同步，名称不绑定首都、在位者或未完成事件。

## 法律偏好

- 联邦国防主义：替换沙文主义；强烈支持职业军队、边疆殖民，支持大规模征兵和全国电力，国民民兵中立，反对农民征召兵与殖民剥削。
- 大陆市场主义：替换已知自由放任、全球发展主义及初始化时已有的新自由主义；强烈支持自由放任和自由贸易，支持政府干预、监管机构、公立大学和电力建设；反对孤立主义、计划经济及严格劳工保护。保留来源中未另行调整的商业、儿童权利和土地立场。
- 公民共和主义：替换共和主义；强烈支持两种共和国和普选，支持人口普查选举，反对独裁、寡头、一党制与世袭统治。
- 公民自由主义：替换普通／现代自由主义；强烈支持多元文化、言论保护、公立大学，支持自由权保障与女性参政，反对秘密警察及军事化警察。保留反教权、反奴隶制和其他理念；共和理念不重复定义公民权。
- 地方宪政主义：替换反动主义或全球共和保守主义；强烈支持民选官僚，支持共和国、保护主义、移民管制、文化排斥；反对世袭官僚、神权政治和封闭边境。保留精英主义、全球公民爱国主义等其他理念。

所有变化仅通过集团法律偏好生效，不发修正、不激活法律。使用原生图标，不新增美术资源。未调整的法律偏好从相应现有理念保留；新增法律组使用当前上游的实际 ID。

## 初始化与边界

新增 `ffpa_usa_ensure_identity_v1`，由既有北美成立回调和 USA 宪章月度包装调用。新形成 USA 立即处理；旧 USA 最迟下一次月度检查补发，不自动申请宪章。名称与理念分别使用 `ffpa_usa_flavor_names_v1`、`ffpa_usa_flavor_ideologies_v1` 一次性标记，政治／经济／治理状态不参与身份判断。

仅替换明确存在的已知来源，尊重未知专属理念，不重建集团或覆盖 `on_enable`。每次只访问八个固定集团；处理过后不重置名称和理念。离开 USA 不再写入，返回时不重放；沿用原生国家形成后的身份继承，不主动清除已赋予的集团名称或理念。

全球生成器的国家优先名单加入大陆市场主义和地方宪政主义，防止通用来源回填。USA 不改写全球理念定义；上游后期逻辑仍处理它拥有的其他理念，不按月恢复 USA 套餐。该边界沿用 TUR/BYZ 的一次性国家转换。
