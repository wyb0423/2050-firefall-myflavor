# USA《联邦的承诺》实施与验证约定

用户于本轮确认优先实现常驻治理，教育科研暂缓；要求文本、结构、样式与图标对齐现有内容。本文件细化 2026-09-08 北美设计 §6.6、§6.8 与 §6.9 的已确认数值，不另建科研常驻日志。

## 范围与依赖

一个永久 JE，两个独立解锁领域，六个按钮，六场双语事件 `.30–31/.40–41/.43–44`。政治完成标记开启信用，工业奖励结算标记开启风险；任一领域完成即可补挂。两领域顺序自由，后加入的领域不重置先加入者。严格 USA 且非革命国家。既有公司、地区工程与政治选择不由治理模块授予或撤销。

核对环境：游戏 1.13 系列，CMF 1.65.0、Tech & Res 1.6'、Firefall 0.1.1，及本项目。目标加载顺序仍以 README 为准。本机 `content_load.json` 当前是其他测试组合，并非该目标栈；没有修改启用组合、启动游戏或据此声称已完成引擎合并验证。

## 治理合同

信用初值60、风险初值25，各自0–100，各有24次首次月度整备检查。信用35以上给合法性+5、官僚产出+8%；20至不足35给+2/+4%；低于20停发。风险65以下给制造业吞吐量/建造效率各+5%；65至不足85各+2.5%；85以上停发。

整备结束后，危险区连续12个月才失败；离开危险区立即清零连续计时。政治重罚8年（合法性−15、官僚产出−15%、法律颁布速度−25%），经济重罚5年（制造业吞吐量−15%、建造效率−20%）。惩罚由状态机立即发放，不由事件点击决定；恢复期间不叠加或刷新。信用至少35、风险低于65分别连续12个月且原生惩罚到期才恢复。未修复时原惩罚仍按原日结束，但收益保持暂停。新一轮真实危机可以再次失败、通知。

普通失败只取消同领域在途加速；另一领域的已付项目继续履约。改 tag 或革命身份失效移除治理收益、取消所有未完项目、不发履约收益；清零连续危机/修复和生活水平观察，保留指标、整备剩余次数、制度、冷却、已结算事件和失败标记。失败修正由原生日期到期，改 tag 不洗掉、不迁给吞并国。返回 USA 不重置惩罚、整备或冷却。已承担的采购审查两年成本仍按原日结束。

## 月度输入与边界

- 信用：合法性至少50且官僚余额非负+0.5；合法性低于30−1；官僚余额负−1；本土动乱至少30%的州占本土人口至少25%时−1。常设审议+0.25；自然变化限制−3至+2。审查的12次额外恢复在自然上限后相加，个人登记每次1.25，否则1。
- 扣除信用档位/失信惩罚的直接合法性贡献。官僚净余额扣除 `produced_bureaucracy / (1 + modifier:country_bureaucracy_mult) × 本日志档位/重罚倍率`；不临时拆装惩罚，避免刷新日期。总倍率非正不能反算时，按行政压力保守处理；此少见引擎边界仍待实机验证。其他真实制度、听证成本与经济后果保留。
- 债务使用原版 `scaled_debt`，不另造 credit 分母；违约或至少90%贡献1.5，60%至不足90%贡献0.5。脚本自身不作债务除法；原生零信用额度行为仍是引擎待验项。
- 制造业复用经济模块的九类明确白名单；已建等级中就业不足65%的比例至少35%贡献1。没有制造业按100%，不视为健康。
- 州生活水平保存前36次月度观测，先比较再加入当月样本。比较同一组有完整历史的州，以当前人口权重分别汇总当月生活水平和各州此前36个月均值，避免取得低生活水平地区本身制造下降压力。新州、换主州重新观察；满36条记录前不计入，因此也涵盖原定取得后首12个月的观察保护。无足够历史不算压力，不用全国均值冒充本土值。下降至少10%持续3个月贡献0.5。
- 债务不足40%、低就业不超过20%、无生活水平压力且未违约，每月风险−1。救济只减半就业/生活水平的压力；不抵消债务。风险自然变化限制−2至+3。
- 月度只访问自有本土州及白名单制造建筑。36个标量槽是原生脚本的有界历史，最多49个州区域内的自有实例；不扫描人口或全世界建筑。州所有权/新州挂钩以本模块历史标记过滤。

## 六项行动

| 行动 | 履约/效果 | 成本与冷却 |
|---|---|---|
| 州际协商 | 一年后信用+12 | 年GDP0.25%的年支出；冷却24月，地方代表18月 |
| 拨款资格审查 | 十二次每月信用+1或1.25；完成时已解锁风险−5 | 建造效率−10%一年；冷却24月 |
| 紧急授权 | 信用立即−15，建造效率+15%一年 | 需已选授权制度且信用≥35；冷却36月 |
| 产业信贷 | 风险立即+15，建造效率+10%一年 | 年GDP0.5%的年支出；风险<65；冷却24月 |
| 特许采购审查 | 一年后风险−15，已解锁信用+5 | 制造业吞吐量−5%、工业家支持−2两年；冷却36月 |
| 救济再培训 | 十二次月度核验减半就业/生活水平压力；履约后已解锁信用+5 | 年GDP0.75%的年支出；冷却24月 |

所有财政金额在启动时按年GDP比例÷52冻结，一年原生费用到期；首次到期后的月度检查确认履约，不把12次检查提前当作满一年。计数为0但原生日尚未到时不多发第13次审查/救济效果。费用汇总仅统计仍存在的费用修正。普通赤字不取消；取消清掉对应费用和完成票据。

紧急授权/信贷共用一个加速槽，两项审查共用一个审查槽。任一领域在危险区或失败恢复时都禁止加速，修复动作保留。AI 使用同一 guard、费用、冷却与结果，优先修复，债务过高时不主动增加付费项目。

## 事件、展示与样式

沿用现有 USA 原版事件窗口、出现音效、政治争论/齿轮动画与天平/工业图标；正文为具体场景、段间空行与一个重点，flavor 为短细节，选项保持短句。数字、期限和风险放悬浮效果中，复杂结算使用 `custom_tooltip` + `hidden_effect`，不重复显示引擎细碎变量操作。

- `.30`：首次审查完成后的听证。追责提高已解锁信用5；只有经济开启时改为风险−5，承担一年官僚产出−5%。也可重排合同，已解锁风险−5（仅政治开启时改为信用+3）并承担一年建造效率−5%。两个选项均可用于任一解锁顺序，绝不暗开未完成的领域。额外代价预先列在审查按钮提示。
- `.31`：首次紧急授权正常到期。选择一年建造效率−5%的补审或再损失5信用。均不续发加速。
- 两项普通争议各一国一次，共享18月调度冷却；独立 pending/serial 使旧弹窗不能修改新状态。失效后在原资格上重新排程，旧票据作废；默认选项提供安全可结算路径。
- `.40/.41` 失败、`.43/.44` 恢复通知不受普通争议冷却阻塞，不在选项中重发处罚/奖励；同月并发各自告知，无联合第三罚。

日志接入 `ffpa_usa_journal_presentation.gui` 的504宽、10间距、原生分隔线、图标和进度纹理。直接复用现有近邻日志的只读进度条形式，不另建缓存；信用正向、风险负向纹理，未解锁领域只显示解锁提示。显示总体最严重状态、两领域数值/增量明细、危机/修复月数、重罚原生剩余时间、费用、在途截止与冷却日期；显示层不驱动玩法。前身、TUR/BYZ界面不变。
