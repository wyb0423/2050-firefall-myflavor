# FFPA — Firefall Flavor Pack

2050年的核战——幸存者后来所称的“大火”——摧毁了东地中海的旧国家，却没有抹去它们的档案、道路、宗教机构与政治记忆。Firefall 让城邦、州级政权与地区继承者重新拼合旧世界国家；FFPA 的故事从这些名字重新出现在地图上之后开始。

重建后的土耳其必须在高门共同体、安卡拉共和国与重建总署之间确定国家遗产；重新形成的希腊则可以把旧档案中的“伟大理想”推向东罗马头衔。成立新罗马并不是终点——复归领土、公共权威、全国福祉、军役户、地方中介和地中海交通网络都将继续检验这些国家能否真正统治大火后的世界。

## 固定依赖与推荐加载顺序

本合集固定面向 Victoria 3 1.13.*、`2050: The Fire Falls` 与 `[1.13] Tech & Res`。它以一个物理 Mod 发布，当前的国家身份、状态机、地区建设与本地化均属于东地中海内部模块。

完整加载栈的推荐顺序如下；未使用某个独立功能包时可从顺序中省略该包：

Tech & Res → Auto-Apply PMs → Auto-Apply Automation PMs → 2050: The Fire Falls → Core Balance Adapter → FFPA Building Pruning → FFPA Building Pruning: Tech & Res Compatibility → FFPA Tech & Res Auto PM Adapter → FFPA Firefall Flavor Pack

## 希腊—东罗马成立链

- Firefall 重新拼合出的 `GRE` 可以接续“伟大理想”政治线，并在君主制下审议东罗马头衔。十九世纪的科莱蒂斯演说只作为幸存档案出现；事件中的政府、军官、教会与法学家都属于大火后的新国家。
- 玩家可以巩固有限的希腊国家、推进完整“伟大理想”，或把民族纲领转化为新罗马国家工程。三条路线分别拥有对应的成功与失败叙事；东罗马路线失败时，文本会准确说明脚本执行的人口撤离与故土移除。
- 成立 `BYZ` 后会保留既有宣称，并由君士坦丁堡的王室、正教会、军队、法学家与行省代表共同确认罗马国号。对外 UI 仍使用易于识别的“拜占庭帝国”，内部叙事主要使用东罗马、罗马帝国与新罗马。

## 土耳其：三种建国遗产与有限边疆

- 完成“重建安纳托利亚”后，国家遗产固定为三条互斥路线之一：高门与奥斯曼共同体、安卡拉共和国、安纳托利亚重建总署。三条路线分别处理宪章与行省妥协、议会与文武关系、地籍与国家开发；后续政体变化不会静默改写建国路线。
- 奥斯曼共同体沿行政整合、公民包容与内部稳定三轴推进。各轴条件独立计算，不满足时逐月倒退而非清零；完成后在保留土耳其文化的同时加入“奥斯曼”主流文化。
- TUR 会幂等补齐 Firefall 成立清单中的 11 个核心州宣称。路线终局后，边疆委员会一次只授权一条路线专属前线：共和国限于西色雷斯与摩苏尔，重建总署止于鲁米利亚—黎凡特—美索不达米亚，高门才可逐步延伸至爱琴海、埃及与伊弗里基亚。
- 前线期限为 15 或 20 年；超时或主动撤回保留已经取得的领土，只清理由本机制添加在未取得州上的临时宣称，并进入五年冷却。到期时若仍在战争或外交博弈中，会等待和平后结算。成功事件在能够可靠恢复对象时，会以中性措辞点名最后一处目标领土的直接前所有者。
- 黑海生命线、东部高原测绘、丘库罗瓦—幼发拉底工程与安纳托利亚干线四项完成其三后会召开计划大会；“两洲之门”完成后还可在开放通行、主权监护与要塞化海峡之间选择一种制度。
- 长期重建结束后，TUR 需要持续调节“帝国簿册与行省中介”的中央—地方平衡，并通过现代战略储备应对首都谷物、运输、电力和市场接入异常。鲁米利亚、东方水利贸易与非洲港口治理会议只讨论官员任命、代表权、财政、公共服务与区域分工，不会再次授予历史宣称。

## 新罗马：共同体、复归与常驻治理

- BYZ 的罗马共同体同样沿行政整合、公民包容与内部稳定三轴推进。完成后保留希腊文化、加入“罗马人”主流文化，并永久提高 20% 符合条件的文化同化速度。
- 御前会议可以选择七项分区复归战争，最多同时推进两项，期限按地区规模为 10、12 或 15 年。成功后可在八年“复归和议”（加快恶名衰减，但牺牲外交博弈机动、威望与军方支持）与五年凯旋奖励之间选择；随后还能以五年持续财政支出和按比例削减官僚机构产出为代价，对本次实际取得的州实施弱、中、强三档十年安置方案，加快整合与移民，并持续减少政治运动产生的激进派、增加忠诚派。失败承受八年政治惩罚，并在五年后重试。成功叙事会在事实允许时点名最后关键州的直接前所有者，无法可靠恢复时自然使用无国名文本。
- 双重重建完成后，“罗马人的公共体”要求分别维持公共权威、全国福祉与公共认同；它们会独立预警、破裂与修复。“军役户与权门”则处理复归战争形成的民兵整编、退伍安置、边疆服役授地和公共工程合同，以及由此成长的新权门。
- 军役户日志包含三阶段制度改革：重编军役户籍时立即落实职业军队或大规模征兵，随后清丈田产与军役，最终设立帝国军需与退伍安置院并永久提高全国福利金。失败会保留已经完成的改革与已经落实的军制法律。
- “西方罗马公民权章程”的三条路线只为现有西方整合白名单中的未整合州提供 `+75%`、`+50%` 或 `+25%` 地区整合速度；后来取得的白名单州会同步获得，完成整合、失去领土或不再是 BYZ 后移除。

## 地区建设与西方整合

- 十五项地区建设覆盖巴尔干、南欧、北非、安纳托利亚、黎凡特与美索不达米亚。它们发生在领土已经纳入本国统治之后，重点是统一铁路、港务、电网、海关、地籍和行政标准；完成后只给实际工程覆盖州留下对应专精。
- 术语统一使用“内海港群”“伊弗里基亚滨海网络”“西班尼亚滨海”与“古毛里塔尼亚滨海道”，强调历史地理称谓而不是现代国界误读。
- 地区完成状态只通过稳定查询触发一次 TUR 治理会议或 BYZ 西方整合事件，不会反向改写地区日志。四项 BYZ 西方整合会议提供彼此独立的永久制度选择。
- “两洲之门”和“复兴新罗马”提供建设期加速；完成后分别选择互斥的永久都会专精，避免同一首都叠加全部强力奖励。

## 旧存档与 Tech & Res 兼容

- 月度国家脉冲会幂等迁移共同体三轴、补建缺少原生多进度条的日志实例、补发缺失日志与一次性标记，并避免重复发放永久奖励。
- TUR 会从仍在运行的共同体、奥斯曼文化或永久公民权修正推断旧档建国路线；若十年重建实用主义已经到期而无法可靠推断，则提供一次性“确认重建时代的国家遗产”决议。
- 活动旧档前线与复归战争只从载入时的当前所有者开始建立叙事快照，不猜测已经丢失的历史；因此载入即完成的旧日志可以安全使用无国名结果文本。
- FFPA 管理的 TUR 不再进入 Tech & Res 的旧奥斯曼崩溃日志。旧档中的活动实例会失效并清理运行状态；T&R 已提前排程的个别叙事事件仍可能在迁移后的短期内出现一次，但不会重新激活日志或执行领土拆分。

## 外部拆分包与发布连续性

本合集继续使用既有 Mod ID `com.wyb.2050-firefall-personal-adapter`，以保留发布与存档连续性。技术 ID、事件 ID 和版本化持久变量均视为存档接口。

以下功能已经拆分为彼此独立的同级 Mod，本合集不重新定义、复制或调用其运行时对象：

- `2050 Firefall — Core Balance Adapter`（`com.wyb.2050-firefall-core-balance`）：人口恢复、创新上限与科技扩散、制度和贸易中心适配、统一战争恶名及殖民塑形。
- `FFPA — Low-Workforce Building Pruning`（`com.wyb.ffpa-building-pruning`）及 Tech & Res 兼容包（`com.wyb.ffpa-building-pruning-techres`）：低人力亏损建筑清理。
- `FFPA — Tech & Res Auto PM Adapter`（`com.wyb.ffpa-techres-auto-pm-adapter`）：Tech & Res 与两个 Auto-Apply Mod 的自动生产兼容。

本合集不把这些外部包声明为硬依赖。需要恢复拆分前的完整功能时，应按推荐顺序同时启用；旧存档也必须保留对应外部包，才能继续获得各自拥有的状态机与界面。

## 未来扩展约定

- 新地区默认继续适配 Firefall 与 Tech & Res，不静默扩大整个合集的硬依赖。
- 每个地区使用独立文件名、事件 namespace、技术 ID、持久变量和本地化键前缀。
- 跨地区联动通过命名明确的 scripted trigger 或 scripted effect，不直接读取另一地区的临时变量。
- 现有东地中海的 `ffpa_flavor.*`、`ffpa_tur_*`、`ffpa_byz_*`、`ffpa_region_*` 及版本化变量属于存档接口，不因内部整理而重编号或改名。
